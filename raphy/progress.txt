## Codebase Patterns
- Semantic-change safety: before trusting caller tests to pin a semantic, corpus-diff the REAL production literals (contracts event tables, kernel payload maps) old-vs-new. Test fixtures may use legacy shapes that pass under both semantics and give false confidence (RA-005: debug tests used unprefixed eps, production emits spine.-prefixed).
- The codebase has an established "converge N identical X into one shared Y" idiom (git: ba2ad56c6 converged 8 `_fail` builders into `tools._shared.fail_observation`; 2a2059cca converged 5 `_emit` closures into `events.emit_fact_event`; 9fecd23a0 deduped `_latest_run` into `domain.latest_run`). New convergence stories should follow this exact shape: extract, delegate, grep-verify single call site, pin behavior with tests.
- Assistant event emitters use a no-emitter-fallback seam: `if self._emit is None: log.info('<scope>.ep.no_emitter', ...)` else `self._emit(EVENT, payload.to_dict())`. The log scope string differs per caller (assistant.catalog / assistant.tool_overlay / assistant.skill_overlay) and must be preserved as a parameter, not hardcoded, when converging.
- `tools._shared.fail_observation` is NOT behavior-identical to the `_fail` methods in `delegate_tool.py` (different Observation construction: payload=None/error=/extra= vs payload dict). Do not conflate them.
- Round 2 (ralph) owns: DecisionGates flattening, Ingest pipeline, ContextFiles shims, Read Runs micro-dirs, full regression. `lca/cognition/memory/` is frozen per Round 2 AP-01. Raphy stories must not touch these.
- Test commands: `uv run pytest <path> --no-cov -q`; lint: `uv run ruff check` on touched files.
- `@plugin` discovery is per-module-single-setup (`profile/resolve/resolve.py` reads `getattr(module, "setup", None)` and id-checks it against the bundle entry): a table-driven loop inside ONE module cannot expose N registrations -- only the last survives. Converge plugin shells via a factory called once per thin module, never via a loop in one module. Gate-probe the discovery mechanism before choosing the shape (RA-008). Branch for this work: `raphy/arch-optimize` (created from main by the first optimize iteration).

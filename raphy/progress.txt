## Codebase Patterns
- The codebase has an established "converge N identical X into one shared Y" idiom (git: ba2ad56c6 converged 8 `_fail` builders into `tools._shared.fail_observation`; 2a2059cca converged 5 `_emit` closures into `events.emit_fact_event`; 9fecd23a0 deduped `_latest_run` into `domain.latest_run`). New convergence stories should follow this exact shape: extract, delegate, grep-verify single call site, pin behavior with tests.
- Assistant event emitters use a no-emitter-fallback seam: `if self._emit is None: log.info('<scope>.ep.no_emitter', ...)` else `self._emit(EVENT, payload.to_dict())`. - `tools._shared.fail_observation` is NOT behavior-identical to the `_fail` methods in `delegate_tool.py` (different Observation construction: payload=None/error=/extra= vs payload dict). Do not conflate them.
- Round 2 (ralph) owns: DecisionGates flattening, Ingest pipeline, ContextFiles shims, Read Runs micro-dirs, full regression. `lca/cognition/memory/` is frozen per Round 2 AP-01. Raphy stories must not touch these.
- Test commands: `uv run pytest <path> --no-cov -q`; lint: `uv run ruff check` on touched files. Branch for this work: `raphy/arch-optimize` (created from main by the first optimize iteration).

## 2026-10-06 21:5x - RA-003 (fresh session) - DROPPED
- Investigated unifying `_emit_lifecycle_pre/post/fail` in
  lca/plugins/events/hooks/model_visible/adapter.py behind one dispatch seam.
  Verdict: **dropped, not forced** — the three phases need genuinely different seams.
- Evidence:
  - pre: `(hook, kwargs)` -> `_model_identity(kwargs)` -> `request_model(turn, step, provider, model)`
  - post: `(hook, response)` -> `_tool_calls_payload` + text/usage extraction ->
    `complete_model(turn, step, usage, content, tool_calls)`; carries a behavior-critical
    docstring (appending here duplicates every turn in derive_messages) that must stay
    with the phase, not a generic seam.
  - fail: `(hook, error)` -> `fail_model(turn, step, error)` direct passthrough.
  - Shared scaffolding is 2 lines of idiom (`step = hook._step_counter` + deferred import),
    and the three deferred imports bind DIFFERENT names — not even the import is shared.
  - A unified seam would need getattr string-dispatch or Callable+**kwargs threading:
    explicit, type-safe direct calls traded for indirection. Deletion test fails.
  - Closed phase set (exactly pre/post/fail); no future-phase leverage.
- No code changed. Targeted tests: 229 passed, 1 pre-existing unrelated failure
  (tests/scenario/profile/test_profile_resolve_boot.py — lca_kernel.boot.boot missing
  attribute, zero tracked modifications in tree, unrelated to model_visible).
- prd.json: RA-003 `"dropped": true` with reason in notes; `passes` left false per
  the no-fake-pass rule.
- **Learnings for future iterations:**
  - "Same shape" != "same seam": diff the imported names and call signatures before
    claiming duplication — here the imports differed, which kills the unification case.
  - A docstring that documents a behavioral trap (double-append) is load-bearing;
    converging the function would orphan or dilute it. Check for such docstrings
    before converging.
  - When the assess session flags a story "worth exploring / droppable", the explore
    step is real work: investigate, decide, record — dropping with evidence is a
    completed iteration, not a skipped one.

# AGENTS.md

这是你在当前工作区的专属操作手册，由你自行书写和维护。
你的核心指令规定了你的通用工作方式，而本文件用于记录你在工作实践中总结出的具体、持久的教训与工作约定——即希望未来的会话能够了解的内容。
这里不记录用户信息（请记录于 `USER.md` 与长期记忆），也不记录你的人格（请记录于 `SOUL.md`）；它只关乎你如何在这个工作区交付高质量成果。

## 约定（Conventions）
每当总结出值得保留的本地工作规则或习惯时在此记录，例如：
- **工作区边界**：工具调用与文件生成默认以当前 Home 的 `workspace/` 目录为边界，所有交付物、数据导出与临时产物均写入 `workspace/` 并定期维护；
- **配置与安全闸门**：助理自身的核心配置修改必须经由 Catalog 的 `revise_profile` 接口或系统向导完成，严禁直接手改磁盘配置面文件破坏版本摘要；
- **真实环境与智库依赖**：涉及全局架构、技术选型或服务端口时，优先查阅组织或本地智库；本工程代码库专属于认知 Agent 本身，不提交外部运维资产；
- **外部服务交互**：调用外部 API 或长耗时命令时遵循幂等与超时保护，行之有效的工作流模式或必须遵守的命令包装规则沉淀在此。

本文件初始时小而精确，随工作逐步生长。切忌填充无用空话；简短准确的文件胜过冗长过时的废话。

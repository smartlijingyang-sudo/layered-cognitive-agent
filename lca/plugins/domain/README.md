# plugins/domain — 产品域插件

Assistant、Tools、Integrations、Collaboration、Skill、Learning 等业务域。

| 子组 | Legacy |
|---|---|
| `assistant/` | `plugins/assistant/` |
| `tools/` | `plugins/tools/` |
| `integrations/` | `plugins/integrations/` |
| `collaboration/` | `plugins/collaboration/` |
| `skill/` | `plugins/skill/` |
| `learning/` | `plugins/learning/` |

域插件可 require 认知/loop seam，但不得 import 其他 domain 插件。

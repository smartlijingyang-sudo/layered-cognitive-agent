# ADR-0246 M2-M4: 用户机器副作用平面全流程实现计划

> **For Antigravity:** REQUIRED WORKFLOW: Use `.agent/workflows/execute-plan.md` to execute this plan in single-flow mode.

**Goal:** 完成 ADR-0246 M2-M4 全流程闭环：实现 Gateway Device Code 配对端点、生产级本地 Companion 守护进程 (`lca-companion`)、前端设备配对交互补丁以及端到端全链路集成验证。

**Architecture:** 
- 控制面：在 `device_hub` 增加标准 RFC 8628 Device Flow 配对服务与端点。
- 执行器：提供独立的 `lca-companion` 进程，通过出站 WebSocket 连接 Gateway，本地二次刚性校验 `CapabilityGrant` 并安全调用 OS 执行。
- 前端：遵循 LCA 规范，通过 `deploy/lobehub/patches/` 为 LobeHub 注入设备配对卡片与执行目标联动。
- 事实源：所有执行回执与事件沉淀入 `Session.append`。

**Tech Stack:** Python 3.11+, Starlette/FastAPI, WebSockets, Pydantic v2, pytest-asyncio, ruff

## Task 4: 全流程端到端集成测试 (E2E)

**Files:**
- Create: `tests/e2e/test_user_machine_full_flow.py`

**Step 1: 编写全链路端到端测试**
- 模拟完整工作流：
  1. Companion 向 Gateway 申请配对；
  2. 模拟前端用户提交 8 位配对码完成授权；
  3. Companion 轮询成功并建立 WebSocket 长连接；
  4. Gateway 识别设备上线；
  5. 构造 `LocalExecPort` 任务分发至该机器执行真实命令；
  6. Companion 本地校验 Grant 并执行，返回 `EffectReceipt`；
  7. 校验回执内容与 exit_code。

**Step 2: 运行测试验证通过并提交**
- 运行 `pytest tests/e2e/test_user_machine_full_flow.py -v`
- `git commit -m "test(e2e): 验证用户机器副作用平面端到端全流程"`

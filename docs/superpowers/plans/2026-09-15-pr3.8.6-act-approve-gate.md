**Goal.** Add a typed-boundary node `act.approve.gate` under
`phase:intervene` (sibling region, **not** `phase:act`). When
`act.authorize` produces `decision.needs_approval=True`, route to this
node; otherwise pass-through. On approval, re-route to `act.envelope`. On
timeout / abandon, abort. Closes the gap surfaced by
`01-industry-matrix.md` rows 6, 13, 22, 24, 26.

**Spec.** `2026-09-15-pr3.8-borrowed-nodes-design.md`
§2.6 + `docs/adr/0228-plan-intervene-delegate-subgraphs.md` (sibling
region) + `docs/adr/0078-hil-approval-state-machine.md` (state semantics) +
`03-six-column-0206.md` M1 attachment §2 (interrupt before envelope).

**Predecessor PRs.** PR-3.5, PR-3.5.1, PR-3.6, **PR-3.7.c**
(`113c1336e feat(intervene): add intervene.resume typed boundary node +
Command contract` and `b4c4abcd2 feat(intervene): add intervene.interrupt

## Task 1: implement `act.approve.gate` node

**Files.**
- Create: `lca/nodes/intervene/approve_gate.py`
- Create: `tests/intervene/test_approve_gate_phase_plugin.py`

**Interfaces.**
- `semantic_name`: `"act.approve.gate"`
- `region`: `"phase:intervene"`
- `declared_inputs`: `("decision", "command")`  # `command` is the typed
  payload from `lca/contracts/protocols/graph/command.py:22`; carries the
  resume semantics (approve / reject / redirect / resume).
- `declared_outputs`: `("decision", "routing")`
- `node_execute`:
  - If `decision.extra.get("needs_approval", False)` is False → pass-through
    with `RoutingDecision(next_node="act.envelope",
    reason="approve_skipped")`. (`Decision.extra` is the
    explicitly-named bag for non-typed metadata per
    `lca/contracts/models/core/execution/decision.py:84`.)
  - If `decision.extra.get("needs_approval")` is True and `approval_state`
    is None → emit `RoutingDecision(next_node="intervene.interrupt",
    reason="approve_interrupt")` and the original `decision`. The
    interrupt (`lca/nodes/intervene/interrupt.py` from PR-3.7.c) handles
    pause + `Command` collection; on resume the bundle routes back to
    this node with `approval_state` populated.
  - If `approval_state.kind == "approve"` → emit the original `decision`
    and `RoutingDecision(next_node="act.envelope",
    reason="approve_approved")`. (Reuse the existing
    `Command` BaseModel at `lca/contracts/protocols/graph/command.py:22`,
    where `kind: Literal["resume", "approve", "reject", "redirect"]`.)
  - If `approval_state.kind == "reject"` or `"redirect"` to abandon, or
    timeout exceeded → emit `RoutingDecision(next_node="terminal.commit",
    reason="approve_rejected")` and the original `decision`.

  Use the existing `Decision`, `RoutingDecision`, and `Command` types.
  Do not introduce a new `ApprovalState` type; reuse `Command` from
  `lca/contracts/protocols/graph/command.py:22` for both the interrupt
  payload and the resume payload.

**Acceptance.**
- `pytest tests/intervene/test_approve_gate_phase_plugin.py` — 4 cases:
  (1) `decision.extra["needs_approval"]=True` → interrupt path,
  (2) `decision.extra["needs_approval"]` absent or False → pass-through,
  (3) `command.kind="reject"` or timeout → abort (route to terminal.commit),
  (4) idempotent (call twice with same input produces same output).
- `ruff check` + `ruff format` clean on the new file.
- Hand-written `@plugin(...)` carrier.
- Fail-closed test: a synthetic profile with no `approval_resume_node`
  edge must fail at `validate_profile_plans` with a clear error.

## Task 2: wire `act.approve.gate` into the bundle

**Files.**
- Modify: `bundles/outer/phase_main.yaml` (add outer edges)
- Modify: `bundles/intervene/subgraph.yaml` (or create if absent) —
  registers `act.approve.gate` under the intervene region
- Modify: `bundles/act/act_subgraph.yaml` (no node added; only the
  `act.authorize → ?` edge acquires a branch)

**Interfaces.**
- `act.authorize` already emits `decision.needs_approval` flag (existing
  field). Confirm the flag name matches the node's contract.
- Outer edges (in `phase_main.yaml`):
  - `from: act.authorize, to: act.approve.gate, when: { kind: eq, port: {
    name: decision.extra }, field: needs_approval, value: true }`
  - `from: act.approve.gate, to: intervene.interrupt, when: { kind: eq,
    port: { name: routing }, field: reason, value: "approve_interrupt" }`
  - `from: act.approve.gate, to: act.envelope, when: { kind: in, port: {
    name: routing }, field: reason, values: ["approve_skipped",
    "approve_approved"] }`
  - `from: act.approve.gate, to: terminal.commit, when: { kind: in, port:
    { name: routing }, field: reason, values: ["approve_rejected"] }`
  - **Resume edge**: `from: intervene.resume, to: act.approve.gate, when:
    { kind: exists, port: { name: command } }` (re-enter the gate with
    the `command` payload populated).

  **Boot fail-loud**: the `approval_resume_node` check is implemented at
  the bundle validate level — `validate_profile_plans` must error if the
  resume edge is missing.

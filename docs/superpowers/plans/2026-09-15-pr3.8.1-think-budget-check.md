**Goal.** Add a typed-boundary node `think.budget.check` that reads
`BudgetLedger` and emits `RoutingDecision{next_node ∈ {think.context.compact,
terminal.commit}, reason ∈ {budget_ok, budget_exceeded_*}}`. This honors
ADR-0225 (no per-node max_visits) and closes the gap surfaced by
`01-industry-matrix.md` rows 14, 16.

## Task 1: implement `think.budget.check` node

**Files.**
- Create: `lca/nodes/think/budget_check.py`
- Create: `tests/think/test_budget_check_phase_plugin.py`

**Interfaces.**
- `semantic_name`: `"think.budget.check"`
- `region`: `"phase:think"`
- `declared_inputs`: `("state",)`
- `declared_outputs`: `("routing",)`
- `node_execute`: read `state.budget_ledger`; if any cap exceeded
  (`max_turns`, `max_tokens`, `max_cost`) → emit
  `RoutingDecision(next_node="terminal.commit", should_stop=True,
  reason=f"budget_exceeded_{kind}")`; otherwise →
  `RoutingDecision(next_node="think.context.compact", should_stop=False,
  reason="budget_ok")`.

  Use the existing `RoutingDecision` dataclass from
  `lca.contracts.protocols.graph.routing`. `BudgetLedger` is the existing
  capability port from ADR-0197; do not introduce a parallel budget type.

**Acceptance.**
- `pytest tests/think/test_budget_check_phase_plugin.py` — new test file
  with 4 cases: (1) under caps → `next_node="think.context.compact"`,
  (2) `max_turns` exceeded → `next_node="terminal.commit"`,
  (3) `max_tokens` exceeded → `next_node="terminal.commit"`,
  (4) idempotent (call twice with same state produces same output).
- `ruff check` + `ruff format` clean on the new file.
- Hand-written `@plugin(...)` carrier (not `@graph_node`, per ADR-0228 +
  PR-3.7.a).

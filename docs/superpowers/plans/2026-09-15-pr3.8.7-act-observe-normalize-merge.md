## Task 1: strengthen `act.observe` to normalize the receipt

**Files.**
- Modify: `lca/nodes/act/observe/observe.py` (existing)
- Create: `tests/act/test_observe_normalize_phase_plugin.py`

**Interfaces.**
- `act.observe` (existing):
  - `semantic_name`: `"act.observe"`
  - `region`: `"phase:act"`
  - `declared_inputs`: `("receipt",)` (existing; unchanged)
  - `declared_outputs`: `("receipt", "routing")` (existing; unchanged)
- `node_execute` (existing body, strengthened):
  - **Before**: take `receipt`, emit `(receipt, should_terminate)` only.
  - **After**: take `receipt`, **normalize** (apply existing
    schema/spill/coerce steps that the body used to do elsewhere), then
    emit `(normalized_receipt, should_terminate)` with
    `RoutingDecision(next_node="reflect.main" | "think.main" |
    "terminal.commit", reason=...)` as before.
  - Normalization rules (existing semantics, lifted into this node):
    - Strip non-serializable fields.
    - Coerce bytes to base64-string if length ≤ 50_000 bytes (per
      ADR-0197 `guard.tool-result-spill` threshold).
    - Spill to a side artifact reference if length > 50_000 bytes; emit
      a stub receipt with `spill_ref` set.
    - If `receipt.error_kind` is set, populate `error_reason` from a
      closed-set map (deterministic, no exception).

**Acceptance.**
- `pytest tests/act/test_observe_normalize_phase_plugin.py` — 4 cases:
  (1) well-formed receipt → pass-through normalized,
  (2) oversized payload → spill_ref set, body stub emitted,
  (3) error_kind set → error_reason populated from closed-set map,
  (4) idempotent (call twice with same input produces same output).
- Existing `act.observe` tests still pass (no signature change).
- `ruff check` + `ruff format` clean on the modified file.

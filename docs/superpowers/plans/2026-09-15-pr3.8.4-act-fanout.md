## Task 1: implement `act.fanout` node

**Files.**
- Create: `lca/nodes/act/fanout.py`
- Create: `tests/act/test_fanout_dispatch_phase_plugin.py`

**Interfaces.**
- `semantic_name`: `"act.fanout"`
- `region`: `"phase:act"`
- `declared_inputs`: `("envelope",)`
- `declared_outputs`: `("envelopes", "routing")`
- `node_execute`:
  - If `envelope` is `None` → emit empty `envelopes` list and
    `RoutingDecision(next_node="act.dispatch", reason="fanout_empty")`.
  - Otherwise → emit `[envelope]` (a list of length 1) and
    `RoutingDecision(next_node="act.dispatch", reason="fanout_1to1")`.

  Use the existing `CommandEnvelope` and `RoutingDecision` types. Do not
  mint a parallel envelope type. Do not call into Body, Registry, or
  SafeExecutor. The node is pure orchestration.

**Acceptance.**
- `pytest tests/act/test_fanout_dispatch_phase_plugin.py` — 4 cases:
  (1) single envelope → list of one,
  (2) missing envelope → empty list,
  (3) idempotent (call twice with same input produces same output),
  (4) `envelopes[0]` equals input envelope (no mutation — type and content
  equality).
- `ruff check` + `ruff format` clean on the new file.
- Hand-written `@plugin(...)` carrier.

**Interfaces.**

- Replace edge: `from: act.envelope, to: act.dispatch` →
  - `from: act.envelope, to: act.fanout`
  - `from: act.fanout, to: act.dispatch, when: { kind: eq, port: { name:
    routing }, field: reason, value: "fanout_1to1" }`

  **Note on missing-input path**: empty `envelopes` would normally require
  a fanout-empty routing, but `act.envelope` only mints a non-`None`
  envelope in this PR's scope (no empty-mint allowed by upstream wiring).
  If a future PR allows envelope to be `None`, add an edge

## Task 1: implement `act.join` node

**Files.**
- Create: `lca/nodes/act/join.py`
- Create: `tests/act/test_join_barrier_phase_plugin.py`

**Interfaces.**
- `semantic_name`: `"act.join"`
- `region`: `"phase:act"`
- `declared_inputs`: `("receipts",)`
- `declared_outputs`: `("receipt", "routing")`
- `node_execute`:
  - If `receipts` is empty → emit empty `NodeOutput` (upstream produced
    nothing; let the bundle edge decide what to do).
  - If `receipts` has length 1 → emit that single receipt and
    `RoutingDecision(next_node="act.observe", reason="join_1to1")`.
  - If `receipts` has length > 1 → **this PR's path is undecided**. Two
    options:
    1. Reject: emit `RoutingDecision(next_node="terminal.commit",
       reason="join_rejects_parallel_in_v1")` and an empty `NodeOutput`.
    2. Pass-through: emit `receipts[0]` and `RoutingDecision(next_node=
       "act.observe", reason="join_partial_first_in_v1")`.

    **Decision: option (1) — reject**. This is fail-loud. The N:N partial-
    failure policy is a follow-up PR; receiving `receipts` of length > 1
    before that PR lands means upstream wiring violated the 1:1 invariant
    this series establishes, and the run must abort rather than silently
    pick one receipt.

  Use the existing `EffectReceipt` and `RoutingDecision` types. Do not
  mint a parallel receipt type.

**Acceptance.**
- `pytest tests/act/test_join_barrier_phase_plugin.py` — 4 cases:
  (1) single receipt → pass-through,
  (2) empty list → empty output,
  (3) length>1 → reject (route to terminal.commit, no `receipt` emitted),
  (4) idempotent (call twice with same input produces same output).
- `ruff check` + `ruff format` clean on the new file.
- Hand-written `@plugin(...)` carrier.

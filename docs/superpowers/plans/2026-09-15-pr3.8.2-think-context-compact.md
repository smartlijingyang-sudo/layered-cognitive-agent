## Task 1: implement `think.context.compact` node + `CompactReceipt` DTO

**Files.**
- Create: `lca/contracts/dto/compact_receipt.py`
- Create: `lca/nodes/think/context_compact.py`
- Create: `tests/think/test_context_compact_phase_plugin.py`
- Create: `tests/contracts/test_compact_receipt.py`

**Interfaces.**
- `CompactReceipt` — Pydantic model, `frozen=True`, `extra="forbid"`. Fields:
  `compacted: bool`, `bytes_before: int`, `bytes_after: int`,
  `strategy: Literal["noop", "truncate_oldest", "summarize", "spill"]`,
  `at: datetime` (UTC, no tz leak).
- `think.context.compact`:
  - `semantic_name`: `"think.context.compact"`
  - `region`: `"phase:think"`
  - `declared_inputs`: `("writer", "state")`
  - `declared_outputs`: `("compact_receipt", "routing")`
  - `node_execute`: read `state.compaction_threshold` and `writer.used_bytes`;
    if below threshold → emit `CompactReceipt(strategy="noop", ...)` and
    `RoutingDecision(next_node="think.history.assemble",
    reason="compact_noop")`. If above → call the existing compaction
    module, emit `CompactReceipt(strategy=..., ...)` and
    `RoutingDecision(next_node="think.history.assemble",
    reason="compact_done")`. If the compaction module raises → emit
    `RoutingDecision(next_node="think.route.decide",
    reason="compact_skipped_error")` and an empty `CompactReceipt` (so the
    rest of the graph sees a typed value, never an exception).

**Acceptance.**
- `pytest tests/think/test_context_compact_phase_plugin.py` — 4 cases:
  (1) under threshold → noop, (2) over threshold → emit receipt,
  (3) missing `writer` → empty `NodeOutput`, (4) idempotent.
- `pytest tests/contracts/test_compact_receipt.py` — schema tests:
  frozen, forbid extra, valid strategy values, datetime UTC.
- `ruff check` + `ruff format` clean on the new files.
- Hand-written `@plugin(...)` carrier.

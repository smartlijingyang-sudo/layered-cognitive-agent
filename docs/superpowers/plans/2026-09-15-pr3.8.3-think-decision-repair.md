**Goal.** Add a typed-boundary node `think.decision.repair` between
`think.decision.parse` and `think.gate` that handles truncated JSON,
schema mismatch, and missing-tool-name. Either repairs the `Decision` and
forwards to Gate, or rejects and re-routes to `think.route.decide` for full
re-reason. Closes the gap surfaced by `01-industry-matrix.md` rows 28, 29.

**Spec.** `2026-09-15-pr3.8-borrowed-nodes-design.md`
§2.3 + `docs/adr/0219-phase-graph-unification.md` §5.5 (typed ports) +
`docs/adr/0047-tool-call-wire-anticorruption.md` (wire-block semantics).

**Predecessor PRs.** PR-3.5, PR-3.5.1, PR-3.6.

**Out of scope.** Tool-name normalization (stays at SE per ADR-0047);
LLM-provider retry (stays at primitive level).

## Task 1: implement `think.decision.repair` node

**Files.**
- Create: `lca/nodes/think/decision_repair.py`
- Create: `tests/think/test_decision_repair_phase_plugin.py`

**Interfaces.**
- `semantic_name`: `"think.decision.repair"`
- `region`: `"phase:think"`
- `declared_inputs`: `("decision",)`
- `declared_outputs`: `("decision", "routing")`
- `node_execute`:
  - If `decision` is `None` or empty → emit empty `NodeOutput` (the upstream
    parse produced nothing; let the bundle edge decide what to do — typical
    wiring: edge with `when: eq port.decision value: None` re-routes to
    `think.route.decide`).
  - If `decision.tool_calls[*].tool_name` is empty or unknown → emit
    `RoutingDecision(next_node="think.route.decide",
    reason="decision_rejected_schema")` and the original `decision` (do not
    mutate). (Per `lca/contracts/models/core/execution/decision.py:29`,
    the field is `tool_name`, not `name`.)
  - If `decision.tool_calls[*].arguments` fails JSON validation against
    the tool's input schema → attempt one deterministic repair (close
    braces, strip trailing comma). If repair succeeds → emit the repaired
    `Decision` and `RoutingDecision(next_node="think.gate",
    reason="decision_repaired")`. If repair fails → emit original and
    `RoutingDecision(next_node="think.route.decide",
    reason="decision_rejected_truncated")`.
  - Otherwise → pass-through with `RoutingDecision(next_node="think.gate",
    reason="decision_ok")`.

  Use the existing `Decision` and `RoutingDecision` types. Schema validation
  uses the existing tool-schema registry (per ADR-0047).

**Acceptance.**
- `pytest tests/think/test_decision_repair_phase_plugin.py` — 4 cases:
  (1) well-formed Decision → pass-through to gate,
  (2) truncated JSON → repair and forward,
  (3) schema mismatch → reject and re-route to route.decide,
  (4) idempotent (call twice with same input produces same output).
- `ruff check` + `ruff format` clean on the new file.
- Hand-written `@plugin(...)` carrier.

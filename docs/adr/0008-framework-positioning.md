# ADR-0008: 框架定位与差异化

## 状态
Accepted

## 背景
LLM Agent 框架生态已有 LangGraph、CrewAI、AutoGen 等成熟选项。LCA 需要明确自己的位置，而不是"用一个新故事替代已有故事"。

## 决定
LCA 的核心差异化是两个维度的同时优先：

1. **认知可解释性**：每个 Decision 强制携带 `rationale` 字段，认知过程结构化可追溯。不是事后埋点，而是内建于循环设计。
2. **生产级工程能力**：持久化（Checkpoint）、可观测（Observability by Default）、协议互通（MCP/A2A）从设计之初就是一等公民，不是事后补丁。

对标定位：

| 维度 | LCA 的选择 |
|---|---|
| 编排模型 | 认知闭环 + 可切换 Strategy，兼具可控性与认知可解释性 |
| 上手体验 | 默认路径简单如 CrewAI（三行代码），底层能力深如 LangGraph |
| 互操作 | L0 原生 MCP/A2A，协议本身可插拔 |
| 记忆 | CoALA 四分法 + 可插拔第五类 + 团队级共享/隔离 |

## 后果
- 不是最轻量的（比 CrewAI 重），也不是最灵活的（比 LangGraph 约束多）。
- 目标用户：需要"认知可解释 + 生产级工程能力"的团队，而非纯原型探索。
